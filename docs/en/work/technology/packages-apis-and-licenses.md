# Check packages, APIs, and licenses

AI frequently suggests plausible package names, methods, configuration options, and citations that do not exist or do not match your version.

## Verify before installing

- Find the package through its official registry and project repository
- Check spelling, ownership, maintenance activity, release history, and supported versions
- Read the primary documentation for the exact API
- Review transitive dependencies and install scripts
- Confirm the license is compatible with your project
- Prefer an existing trusted dependency or platform feature when suitable

Do not run an installation command merely because it appears in generated code. A hallucinated package name may resemble a malicious package.

Generated code can also reproduce patterns or text with unclear origin. Follow your organisation's review and licensing policy before distribution.
