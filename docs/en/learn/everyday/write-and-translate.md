# Write and translate messages with AI

AI can turn rough notes into a polite message or translate them into another language.

## Safe steps

1. Remove names, phone numbers, addresses, payment details, and private facts.
2. State the audience, language, and tone.
3. Tell AI not to add promises or facts.
4. Read the result before sending it.
5. Ask a fluent speaker to check high-stakes medical, legal, financial, or safety wording.

## Try this prompt

> Rewrite this as a short, respectful WhatsApp message in Telugu. Preserve every fact and number. Do not add promises. After the translation, explain it back to me in English: [safe text]

Translation can change meaning. Never rely on an unchecked AI translation for consent, medication, dosage, contracts, emergencies, or safety instructions.
