This course is the tutorial for authors. It is itself built the way it teaches: Markdown files in a folder, with
quizzes, code, Mermaid diagrams and flow diagrams in the lessons. Open the lesson files to see exactly how each
example is written.

## What you will build

A small course of your own, from an empty folder to a published course, with a quick check at the end of each lesson.
